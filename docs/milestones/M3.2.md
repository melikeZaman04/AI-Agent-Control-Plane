## Chosen implementation

A single `architect chronicle` command delegates episode generation to M3.1.
`--run` selects an exact full run ID; `--event` requires that run and resolves
an exact supporting event ID; `--json` selects deterministic machine output.
The service's new `evidence` method returns an ArchitectEvent using shared
project validation and normalized-evidence identity checks in a read-only
snapshot. Legacy payloads are not promoted or returned as normalized evidence.
Canonical behavior and examples live in ARCHITECTURE and the root README.
ADR-004 remains applicable, with an M3.2 application note.

selected run evidence; indexing/pagination remains deferred until measured need.

are retained between commands. Original event metadata is displayed only when
explicitly inspecting evidence. No natural-language interpretation is generated.
