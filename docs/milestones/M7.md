# M7 — Learn / Labs

Status: COMPLETE under A3, 2026-09-15.

The versioned packaged corpus contains retry-idempotence and stale-cache failures.
Each scenario provides learner instructions, a faulty fixture and deterministic
acceptance code outside the learner workspace. Explicit LEARN list/start/check/
progress operations create independent local sessions. Checks run fresh snapshots
through bounded POSIX subprocesses; source/check/scenario hashes and atomic JSON
attempt receipts retain actual outcomes. Per-session locks serialize concurrent
attempts. Progress reports last evaluated results and stale-source/check flags;
mastery remains unknown. No agent runtime, schema or dependency was added.

## Limits

Hidden checks are inspectable, not secret. Trusted learner Python has user
permissions; temporary source copies are not security sandboxes. This small
corpus does not implement every example failure category from the product vision.
Retain the corpus version and session files for later hash resolution. Local
progress is evidence of specific check attempts, not tamper-proof certification,
current correctness after edits, or a teaching-quality/model-performance score.

The existing approved roadmap ends here. No further product scope is inferred.
