| Durable decision history | GitHistory.decisions returns tracked regular ADR revisions and blob/source-commit provenance. ## Explicit limits

- Git history is committed, locally available and reachable from the chosen
  revision. No fetch, uncommitted diff, semantic summary or all-branch union.
- Merge changes are first-parent comparisons; timestamp ordering is not causal
  ordering. Renames are D/A. ADR revisions establish document history, not inferred
  acceptance or implementation. New/uncommitted ADRs appear only after a later,
  separately authorized commit.
- Git and SQLite are separate source snapshots; no commit/run attribution is
  inferred. Sources must remain available for later resolution.
- Run failure and failed-tool records describe distinct evidence, not deduplicated
  incidents or explanations. Unknown file/test outcomes remain explicit.
- Automation classification is an optional normalized lifecycle metadata contract;
  existing integrations do not acquire new automation telemetry. No scheduler exists.
- Query-time scans and single-project-per-database ownership remain MVP limits.

(`/changes`, `/day`, `/resume`, `/explain`, natural-language synthesis) is not started.
