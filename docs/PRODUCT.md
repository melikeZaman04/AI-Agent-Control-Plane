# Architect OS Product

Modern coding agents can write code, but users often lose visibility into what an agent did, why a change happened, what context was available, what happened while the human was away, where the project was left, and which model or context strategy performs better.

Architect OS is an AI Agent Control Plane + Project Intelligence System + Context Economy Engine + Agent Engineering Workbench.

It sits above coding agents and does not replace their conversations, code generation, native tools, sandboxes, permissions, or provider session behavior.

## Product Pillars

### Agent Flight Recorder

Observe runs, tool and file activity, tests, failures, approvals, and external side effects when they are observable.

### Project Chronicle

Maintain evidence-backed engineering history: runs, changes, decisions, failures, automations, and test history.

### Context Economy

Reduce repeated repository rediscovery without sacrificing correctness. The future strategy combines bootstrap context, an incremental index, a compact repo map, targeted retrieval, and optional long-term knowledge.

### Engineering Workbench

Architect OS has three distinct product modes:

- BUILD — develop real projects with coding agents.
- LEARN — explore controlled engineering scenarios and failures.
- RESEARCH — compare agents, context strategies, and architecture decisions.
